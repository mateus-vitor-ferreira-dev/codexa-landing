# Codexa Landing

Landing page institucional da Codexa.

**Produção:** `https://digitalcodexa.com` (Vercel)

## Stack

| Camada | Tecnologia |
|---|---|
| Framework | Next.js 15 (App Router) |
| Animações | GSAP 3 + ScrollTrigger |
| Estilo | Tailwind CSS + CSS vars |
| SEO | Schema.org, sitemap, robots.txt, LGPD |
| Hosting | Vercel (auto-deploy) |

## Seções

Hero · Cases · FAQ · Garantias · ComoFunciona · Manifesto · Serviços · Stats · Depoimentos · CTA

## Rodar localmente

```bash
npm install
npm run dev    # http://localhost:3000
```

## Deploy

Push para `main` → deploy automático na Vercel.
